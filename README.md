# Supply-Chain-Management
Developed a Supply Chain Management Analysis project using Excel, Power BI to optimize inventory, reduce costs, and improve delivery operations. The Project focuses on improving supply chain efficiency through data-driven insights and interactive dashboards.

## Project Objective

This project aims to analyze supply chain inventory and sales data using Excel and Power BI to generate actionable business insights. The objective is to optimize inventory levels, reduce operational costs, monitor sales performance, and improve delivery efficiency through interactive dashboards and KPI-driven reporting.

## Tools & Technologies

- Microsoft Excel
- Power BI
- DAX
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)

- Total Sales (MTD, QTD, YTD)
- Product-wise Sales
- Sales Growth
- Daily Sales Trend
- State-wise Sales
- Top 5 Store-wise Sales
- Region-wise Sales
- Total Inventory
- Inventory Value
- Overstock / Out-of-stock / Under-stock Analysis
- Purchase Method-wise Sales

## Project Process

- Collected inventory, product, store, customer, calendar, and geography datasets from Excel files.
- Cleaned the data by removing duplicates, handling missing values, and standardizing formats.
- Transformed the data by creating Month, Quarter, Year, and other calculated fields.
- Loaded the cleaned datasets into Power BI.
- Created relationships between fact and dimension tables using a star schema.
- Developed KPIs such as Total Sales (MTD/QTD/YTD), Product-wise Sales, Sales Growth, Inventory Value, and Stock Status.
- Built interactive dashboards with KPI cards, charts, maps, and slicers.
- Validated dashboard results with Excel calculations to ensure accuracy.
- Published the final dashboard and project documentation on GitHub.

## Business Impact

- Improved inventory visibility
- Identified stock shortages and excess inventory
- Supported cost reduction decisions
- Enhanced sales and delivery performance monitoring
